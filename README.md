# Mi primera web

Proyecto de aprendizaje: una página web sencilla creada paso a paso
para practicar el flujo completo de desarrollo.

## Archivos

- `index.html` — la estructura y el contenido de la página
- `estilos.css` — el aspecto visual (colores, tipografía, tarjetas)
- `app.js` — la interactividad (saludo según la hora y botón contador)

## Cómo verla

Abre `index.html` con doble clic: se abrirá en tu navegador.
